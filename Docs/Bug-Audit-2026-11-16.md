Audit mencakup kode alur permainan dan input, interaksi/procedural animation, api/alat pemadam, 17 scene di Assets/Scenes, serta tes Unity yang tersedia. Perubahan lama dalam working tree dipertahankan. Fitur proposal yang belum dibuat tidak dihitung sebagai bug.

## Bukti dan cakupan pengujian

- Baseline job `2322606e064f4ecbb6f3260c2a31c9e7`: 15 kasus baru, 14 gagal sesuai delapan bug di atas; skenario rescue normal lulus. Ini adalah reproduksi sebelum perbaikan, bukan hasil regresi akhir.
- APAR sesudah wiring, job `d3be77385d094938bb444488163d62fa`: lulus 1/1. Input Tool asli, kontak tangan, arah semprotan, partikel aktif, pengurangan intensitas api, penghalang dinding, dan cleanup setelah drop diperiksa.
- Job awal `a734716a93154a86a369aecdc0a9f6d5` kehilangan riwayat setelah sesi berubah; hasil akhirnya tidak dihitung. Job penuh pengganti `555f08f7c64c45fb8cde615dbc75d976` menyelesaikan 76 kasus: 74 lulus, dua pembacaan input lobby gagal. Kedua skema/action aktif dan terpasang benar; menunggu real-time maupun frame saja belum menyelesaikan event uji. Setelah event keyboard yang diantrekan diproses eksplisit melalui InputSystem.Update sebelum ReadValue, job `bb81a1fa724047f3a0bcc3b7aa3b5d38` lulus 2/2, termasuk penolakan join ganda, berbagi keyboard lintas skema dan pembacaan input independen. Tidak ada perubahan kode produk setelah suite penuh. Secara keseluruhan 76 kasus berbeda lulus melalui run penuh dan pengujian ulang terarah; ini bukan klaim satu job lulus 76/76.
- Satu tes pintu lama mensyaratkan anchor menutup menjadi anak engsel. Syarat itu bertentangan dengan mekanik buka/tutup pada posisi yang sama yang sudah disetujui. Tes kini memeriksa identitas anchor, posisi dunia dalam .001 m dan rotasi dalam .1 derajat tetap, sambil mempertahankan pemeriksaan collider, seleksi, kontak animasi, dan pemulihan kontrol. Tes tersebut lulus; kode pintu tidak diubah.
- Console akhir tidak memuat error/warning. Output tes selang tetap mencatat peringatan lama partial convex hull untuk mesh Sphere; Console akhir yang bersih tidak berarti seluruh run tanpa warning.
- Pemeriksaan referensi: tidak ada missing script pada 17 scene. SampleScene memuat satu referensi sprite lama pada SpriteRenderer PlayerLaserPlane yang nonaktif dari prefab contoh CablePhysics; asset sumbernya tidak tersedia. Referensi demo tersebut tidak diganti dengan gambar tebakan atau perubahan pada mekanik aktif.
- Pemeriksaan SafezoneTrigger.cs melalui MonoScript.GetClass berhasil menemukan SafeZoneTrigger; perbedaan huruf nama file bukan missing script di editor ini.

## Batas verifikasi

Tes coroutine Editor memasuki Unity Play Mode. Pemeriksaan urutan build tidak sama dengan menjalankan executable hasil build, dan input gamepad fisik belum diuji. Dua dugaan dari pembacaan kode—nozzle melewati lingkungan dan leveling meja yang terhalang—belum dihitung sebagai bug terkonfirmasi tanpa reproduksi perilakunya.

Perubahan scene Gameloop pada audit ini hanya empat nilai APAR: referensi origin, asset graph, posisi dan rotasi WaterCanon. Model player, animasi, kurva speed/load, skema input, dan AdaptiveAnimation_Demo tidak diubah oleh perbaikan ini.
